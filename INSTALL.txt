xAI CMS 安装教程
========================================

本文档将指导您完成 xAI CMS 的安装和部署。

1. 环境要求
----------------------------------------
在开始安装之前，请确保您的服务器满足以下最低要求：

* 操作系统: Linux (推荐 Ubuntu / CentOS) 或 Windows
* Web 服务器: Nginx (推荐) 或 Apache
* PHP 版本: PHP 8.0 或更高版本
* 数据库: MySQL 5.7 / 8.0 或 MariaDB 10.3+
* PHP 扩展:
    - pdo_mysql
    - curl
    - mbstring
    - json
    - xml
    - gd 或 imagick

2. 文件上传与目录权限
----------------------------------------
1. [上传文件]
   将 php_backend 目录下的所有文件上传到您的服务器网站根目录
   （例如 /www/wwwroot/your-domain.com）。

2. [设置目录结构]
   建议将 Web 服务器的运行目录（Document Root）指向 public 文件夹，
   而不是项目根目录，以提高安全性。
   - 项目根目录: /path/to/project
   - Web 根目录: /path/to/project/public

3. [设置权限]
   确保 Web 服务器用户（如 www-data 或 www）对项目目录拥有写入权限，
   以便安装程序生成配置文件。
   (Linux 示例: chown -R www:www /path/to/project)

3. Web 服务器与伪静态设置
----------------------------------------
在运行安装程序之前，您必须配置好 Web 服务器的伪静态规则，
否则页面将无法正常访问（出现 404 错误）。

* 详细规则请参考同目录下的 REWRITE.txt 或 伪静态规则.txt 文件。

[宝塔面板快速设置]
1. 进入宝塔面板 -> 网站设置 -> 网站目录，将运行目录设置为 /public。
2. 重要：如果遇到 open_basedir 报错，请在此页面取消勾选“防跨站攻击(open_basedir)”。
3. 进入 伪静态，手动填入 Nginx 规则（见 REWRITE.txt）。

4. 运行安装向导
----------------------------------------
1. 打开浏览器，访问您的域名（例如 http://your-domain.com）。
2. 系统会自动检测到未安装，并跳转至安装向导页面 (/install/index.php)。
3. [第一步：环境检测]
   系统会自动检查服务器环境是否满足要求。如果所有项均为绿色，点击“下一步”。
4. [第二步：数据库配置]
   填写您的 MySQL 数据库信息（主机、端口、数据库名、用户名、密码）。
   点击“测试连接并继续”。
5. [第三步：管理员设置]
   设置后台管理员账号（邮箱、密码）。
   点击“开始安装”。
6. [第四步：完成安装]
   等待安装脚本执行完成。安装成功后，点击“进入首页”。

5. 安装后安全建议
----------------------------------------
1. [删除安装目录]
   为了安全起见，安装完成后请务必删除 public/install 目录。

2. [后台登录]
   默认后台登录地址为：http://your-domain.com/login
